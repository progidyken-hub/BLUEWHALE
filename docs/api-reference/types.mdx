## RoutingResult

The object returned by `extractRouting`.

```typescript
interface RoutingResult {
  address: string;          // Canonical G-address
  routingId: string;        // 64-bit ID string
  warnings: Warning[];      // List of non-fatal issues
  destinationError: string; // Error code for fatal issues
}
```

## Warning

A discriminated union (in TS) or object (Go/Dart) describing a non-fatal issue.

```typescript
type Warning = {
  code: string;             // WarningCode
  severity: 'INFO' | 'WARN' | 'ERROR';
  message: string;
}
```

## ErrorCode (Fatal)
- `INVALID_CHECKSUM`
- `INVALID_DESTINATION` (e.g. C-address)
- `UNSUPPORTED_MEMO_TYPE`

## WarningCode (Non-fatal)
- `REDUNDANT_MEMO`
- `MEMO_TYPE_MISMATCH`
- `NON_ROUTABLE_MEMO`
- `JS_PRECISION_LOSS`

## getMuxedSubaccountId

Extracts the 64-bit subaccount ID from a valid Med25519 (M-address) strkey.

```typescript
function getMuxedSubaccountId(address: string): bigint;
```

Returns the subaccount ID encoded in the M-address as a `bigint`. Throws
`InvalidArgumentError` if the input is a standard G-address or a C-address
(i.e. not a Med25519 address).

```typescript
import { getMuxedSubaccountId } from '@stellar/kit';

const id = getMuxedSubaccountId('M...'); // bigint
```
